# TaskControl

TaskControl - вебдодаток для створення, розподілу та контролю виконання завдань у команді. Система побудована на ASP.NET Core MVC 8, ASP.NET Core Identity та Entity Framework Core з SQL Server / LocalDB.

## Можливості

- реєстрація та авторизація користувачів;
- ролі `Admin`, `Manager`, `Executor`;
- команди, проєкти, задачі та Kanban-дошка;
- контроль дедлайнів, прострочення і ризиків;
- коментарі, історія змін і внутрішні сповіщення;
- dashboard зі статистикою та завантаженістю виконавців;
- демонстраційні seed-дані для швидкого запуску.
